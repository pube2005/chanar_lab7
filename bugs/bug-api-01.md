# BUG-04: API буруу JSON биетэй хүсэлтэд 400 биш 200 OK буцаадаг

**Орчин:** Уншлагын жагсаалт v2.0, Windows 11, PowerShell 5.1, 2026-10-20
**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Терминал (PowerShell) нээнэ.
2. Дараах командыг ажиллуулна:
   `curl.exe -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d "{bad json}"`
3. Хариу гаралтыг харна.

**Хүлээгдэж байсан:** Спецификацийн дагуу "API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана." Тиймээс HTTP статус код нь 400 байх ёстой.
**Бодит үр дүн:** HTTP статус код нь 200 OK буцаж, биет нь {"result":"OK"} гэж байна. (Мөн дутуу талбартай JSON илгээхэд ч 200 OK буцааж, өгөгдлийн согог үүсгэж байна).

**Ноцтой байдал:** Critical (API-ийн аюулгүй байдал, өгөгдлийн бүрэн бүтэн байдалд халдсан)
**Хавсралт:** evidence/bug-api-01.txt (curl -i-ийн бүтэн гаралт)
