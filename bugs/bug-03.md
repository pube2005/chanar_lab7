# BUG-03: 1000-2100-аас гадуур онтой ном нэмэгддэг

**Орчин:** Уншлагын жагсаалт v2.0, Firefox, Windows 11, 2026-10-20
**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. http://localhost:3000 нээнэ.
2. Гарчигт "Тест ном", Зохиолчд "Тест зохиолч" гэж бичнэ.
3. Оны талбарт 990 гэж бичнэ.
4. "Нэмэх" товч дарна.

**Хүлээгдэж байсан:** Спецификацийн дагуу "Он нь 1000-2100 хоорондох бүхэл тоо" байх ёстой. Тиймээс 990 гэсэн утгатай ном нэмэгдэхгүй байх ёстой.
**Бодит үр дүн:** 990 онтой ном хүснэгтэд нэмэгдэж байна.

**Ноцтой байдал:** Major (Спецификацийн хязгаарыг зөрчиж байна)
