# BUG-02: Устгах товч улаан биш, ногоон өнгөтэй байна

**Орчин:** Уншлагын жагсаалт v2.0, Firefox, Windows 11, 2026-10-20
**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. http://localhost:3000 нээнэ.
2. Хүснэгтийн баруун талд байгаа "Устгах" товчийг харна.

**Хүлээгдэж байсан:** Спецификацийн дагуу "Аюултай үйлдлийн товч (Устгах) улаан өнгөтэй" байх ёстой.
**Бодит үр дүн:** "Устгах" товч ногоон өнгөтэй байна.

**Ноцтой байдал:** Minor (Хэрэглэгчийн интерфейсийн гоо зүйн асуудал)
