# BUG-01: Гарчиг болон Зохиолч хоосон байхад ном нэмэгддэг

**Орчин:** Уншлагын жагсаалт v2.0, Firefox, Windows 11, 2026-10-20
**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. http://localhost:3000 нээнэ.
2. Гарчиг, Зохиолч талбарыг хоосон орхино.
3. Оны талбарт 2000 гэж бичнэ.
4. "Нэмэх" товч дарна.

**Хүлээгдэж байсан:** Спецификацийн дагуу "Гарчиг, Зохиолч, Он гурван талбар бүгд заавал бөглөгдсөн байх ёстой; дутуу бол ном нэмэгдэхгүй, ойлгомжтой алдааны мессеж харагдана." Тиймээс ном нэмэгдэхгүй байх ёстой.
**Бодит үр дүн:** Ном нэмэгдэж, хүснэгтэд хоосон гарчиг, хоосон зохиолчтой мөр харагдана.

**Ноцтой байдал:** Major (Өгөгдлийн бүрэн бүтэн байдалд халдаж байна)
